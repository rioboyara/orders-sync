# orders-sync

Мини-синхронизатор заявок: забирает `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`
(10 цифр → дописываем 7, ведущая 8 → 7, всё, что не даёт 11 цифр с 7 в начале, — invalid),
дедуплицирует по телефону (макс. `amount`, при равенстве — более поздний `created_at`) и отдаёт JSON на `GET /result`.

- Стек: Node.js ≥18 без зависимостей (встроенный `fetch`), serverless-функция Vercel `api/result.js`; `server.js` — для запуска на любом Node-хостинге.
- Идемпотентность: результат — чистая функция от входных данных, без накопительного состояния; повтор синка даёт тот же JSON (клиенты отсортированы по телефону).
- Секреты: в коде их нет. Адрес источника — env `ORDERS_URL` (дефолт — публичный URL); токены/ключи, если появятся, — только в Environment Variables хостинга, `.env` в `.gitignore`.

```
npm test
npm start   # http://localhost:3000/result
```
